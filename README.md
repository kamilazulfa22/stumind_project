# 🧠 Stumind

**Stumind (Smart Stunting Monitoring)** adalah platform berbasis web untuk membantu orang tua memantau pertumbuhan dan perkembangan anak serta memberikan edukasi mengenai pencegahan stunting.

---

## 🌱 Tentang Stumind

Stumind hadir sebagai solusi digital untuk membantu:

- Monitoring tinggi dan berat badan anak
- Deteksi risiko stunting sejak dini
- Edukasi kesehatan dan nutrisi anak
- Rekomendasi makanan sehat
- Pemantauan tumbuh kembang secara berkala

Dengan tampilan yang sederhana dan ramah pengguna, Stumind dirancang khusus agar mudah digunakan oleh orang tua.

---

## ✨ Fitur Utama

### 📊 Monitoring Anak
Memantau pertumbuhan anak seperti:
- Tinggi badan
- Berat badan
- Perkembangan fisik

### 🍎 Rekomendasi Nutrisi
Memberikan rekomendasi makanan sehat untuk membantu tumbuh kembang anak.

### 📚 Edukasi Kesehatan
Informasi penting mengenai:
- Apa itu stunting
- Penyebab stunting
- Cara pencegahan stunting
- Nutrisi penting untuk anak

### 🤖 AI Assistant
Membantu memberikan edukasi dan informasi seputar kesehatan anak secara interaktif.
